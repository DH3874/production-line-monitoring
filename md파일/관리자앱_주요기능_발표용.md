# 관리자 앱 주요 기능

> 관리자가 한 화면에서 라인을 보고, 작업자 PC를 원격 제어하고, 문제를 처리하고, 보고서를 자동으로 남기는 프로그램

1. **서버 켜고 접속**: 관리자 PC에서 서버를 켜면 모든 데이터가 서버 한 곳(SQLite DB)에 저장
2. **전체 라인 현황**: 4개 라인 실시간 표시
   - LINE 1: 실제 벨트·센서 상태
   - LINE 2·3·4: 회전 분류판 시뮬레이션 (정상 통과 / 불량 55° 분류)
3. **작업자 원격 운영**: 실시간 검사 영상, 벨트·검사·분류 원격 제어, 온도·습도·가스 그래프
4. **전체 정지**: 실제 라인과 가상 라인을 한 번에 정지, 작업자 정지 응답까지 확인
5. **문제 처리**: 작업자 완료 요청 → 관리자 종결·반려, 문제별 1:1 채팅
6. **검사 이력 / 통계**: 기간별 정상·불량·불량률, 검사 사진 확인
7. **사용자 관리**: 작업자 계정 추가·수정·비활성화, 라인 권한
8. **보고서 자동 저장 (CSV)**: 앱을 끄면 근무 시간 보고서가 자동 저장 (검사 요약, 기종별 분석, 5분 단위 센서, 문제·이벤트)
9. **단체 채팅**: 전체 계정 채팅, 안 읽은 수 표시
