# PUL/DIR 컨베이어 제어 · 현재 프로젝트 통합

제어·업로드 기능은 사용자가 선택한 기존 제어 폴더를 통합했고, 실제 출력 핀·펄스는 이후 제공한 정상 동작 코드에 맞췄습니다. **현재 기본은 인식돼도 멈추지 않는 연속 검출**입니다. [현재 기능·역할 정리](../docs/PROJECT_OVERVIEW_CURRENT.md)를 참고하세요.

## 현재 설정

| 항목 | 값 |
|---|---|
| PUL 핀 | Mega 5번 |
| DIR 핀 / 방향 | Mega 6번 / LOW |
| 펄스 반주기 지연 | `PULSE_DELAY = 80` µs (사용자 정상 동작 코드와 동일) |
| PC 통신 | USB 시리얼, 9600 baud, 줄바꿈 명령 |
| 연결 확인 | `PL_CONVEYOR_PUL_DIR_V3` |
| PC 신호 주기 / 통신 중단 정지 | 500ms / 3000ms |
| 인식 시 정지 | 관련 화면 및 검사 연동 기능 제거 |

사용자가 직접 정상 회전을 확인한 단독 코드의 PUL=5 / DIR=6 / DIR=LOW / 반주기 80µs / 정지 시 PUL=HIGH를 그대로 반영했습니다. 이전 2/3번 핀과 500µs 램프 설정은 제거했습니다. 고정 5초 회전·3초 정지 대신 프로그램의 RUN/STOP을 따릅니다. V3 연결 확인으로 이전 핀 설정 펌웨어는 구동 전에 거부합니다.

## 처음 준비

1. 기존 서버를 실행합니다. 이더넷 주소와 기존 계정을 사용합니다.
2. 솔루션 최상위의 `컨베이어_통합실행.cmd`를 실행하거나 Visual Studio에서 사용자 앱을 실행하고 로그인합니다.
3. 실시간 검사 → **아두이노 설정·업로드** → 실제 Mega COM 포트 선택 → **업로드·연결**을 누릅니다. 처음에는 개발 도구를 다운로드하므로 인터넷이 필요합니다. 이 버튼은 보드의 기존 코드를 현재 앱의 펌웨어로 교체합니다.
4. 업로드 후에는 정지 상태로 연결합니다. 다음부터 코드가 같으면 **COM 선택 → 벨트 연결**만 사용해도 됩니다.

Arduino IDE를 사용하려면 `ConveyorYoloControl/ConveyorYoloControl.ino`를 Mega 2560에 업로드하고 IDE 시리얼 모니터·플로터를 닫으세요. 기존 PUL/DIR 드라이버용 배선·모터 전원을 사용합니다. 이전 V1·V2 펌웨어는 호환되지 않아 앱이 연결을 거부합니다.

## 운영 흐름

1. 카메라 연결 → YOLO 모델 확인 → 검사 시작 → 벨트 구동.
2. 휴대폰을 인식해도 벨트는 계속 이동하고 결과·사진을 서버에 저장합니다.
3. 실시간 화면 오른쪽에는 마지막 인식 제품 사진을 유지합니다.
4. 검사 개수·지난 기록에서 행을 선택하면 해당 기록의 사진을 조회합니다.
5. 검사 중지는 분석·기록만 중지합니다. 검출 정지 체크박스·벨트 정지 버튼·정지 후 검사 및 재구동 기능은 제거했습니다.

## 연결 관리

- 검출과 벨트 구동은 별개이며, 카메라·저장 오류로 검사가 멈춰도 인식에 따른 STOP 명령은 없습니다.
- 벨트 연결 해제·업로드 준비·앱 종료의 기존 연결 정리와 통신 중단 후 3초 펄스 중단은 유지합니다.
- V3 펌웨어의 출력 핀과 펄스 설정은 바꾸지 않았습니다. 이번 PC 화면 변경으로 보드 재업로드는 필요 없습니다.
- 장치 응답은 실제 회전 센서 측정값이 아닙니다. 이번 검증에서는 물리 보드를 업로드하거나 모터를 돌리지 않았습니다.

## 검증 및 백업

사용자 앱과 검증 프로젝트는 분리된 출력 폴더에서 경고·오류 없이 빌드했습니다. 최신 재현 절차와 검증 결과는 [최신 검증·적용 안내](../docs/HISTORY_PHOTOS_VERIFICATION.md)을 참고하세요. 실제 모터 구동·보드 업로드는 하지 않았습니다.

실행 중인 사용자 앱은 이전 코드로 동작합니다. 닫은 뒤 최신 앱을 실행하세요. 이번 변경에서는 보드 펌웨어가 같으므로 이미 V3 펌웨어를 사용 중이면 보드 재업로드는 필요 없습니다. V1·V2나 단독 반복 구동 코드를 사용 중이면 **아두이노 설정·업로드 → 업로드·연결**로 V3를 준비합니다. 사진 저장·조회 기능을 사용하려면 서버와 사용자 앱을 모두 최신 버전으로 다시 실행합니다.
