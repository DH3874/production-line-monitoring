# 아이폰 검사 YOLO 라벨링·학습 도구

C# WinForms 화면에서 사진을 가져오고 YOLO 형식의 박스 라벨을 작성한 뒤, Python Ultralytics 학습과 ONNX 변환을 실행하는 도구입니다.

2026-10-19 현재 솔루션 최상위 프로젝트는 휴대폰 전체 외곽 검출용 `phone` 단일 클래스로 재학습해 적용했습니다. 아래의 3개 기본 클래스는 **새 프로젝트 생성 시** 기준입니다. 기존 프로젝트를 열 때는 해당 `classes.txt`의 실제 클래스 순서를 따르세요. 색상 4종 분류는 `training/phone_colors`의 별도 절차를 사용합니다. [현재 모델 적용 안내](../docs/PHONE_FULL_BODY_TRAINING_20261019.md)

## 기본 클래스

- `target_iphone`: 생산라인에서 정상으로 인정할 목표 아이폰 기종 전체
- `other_phone`: 다른 아이폰 기종과 안드로이드폰 전체
- `crack`: 전면 또는 후면의 깨진 영역

프로젝트마다 `classes.txt`를 수정하거나 화면에서 클래스를 추가할 수 있습니다. 학습을 시작한 뒤 클래스 순서를 변경하면 기존 라벨 번호가 달라지므로 순서를 유지해야 합니다.

## 사용 순서

1. `ProductionLine.TrainingTool`을 실행합니다.
2. **새 프로젝트**에서 학습 자료를 저장할 폴더를 선택합니다.
3. **사진 가져오기**로 JPG·PNG·BMP 사진을 추가합니다.
4. 오른쪽에서 클래스를 선택하고 사진 위에서 마우스로 박스를 그립니다.
5. **라벨 저장**을 누릅니다. `Ctrl+S`로도 저장할 수 있습니다.
6. 모든 사진을 처리한 뒤 **학습 데이터 만들기**를 누릅니다.
7. **Python·YOLO 확인**으로 설치 상태를 확인합니다.
8. 설치되지 않았다면 **YOLO 환경 설치**를 누릅니다.
9. 학습 횟수와 이미지 크기를 정하고 **YOLO 학습 + ONNX 변환**을 누릅니다.

학습 완료 결과는 선택한 프로젝트의 `models/best.pt`와 `models/best.onnx`에 저장됩니다.

## 사진과 라벨 기준

- 목표 아이폰은 휴대폰 외곽 전체에 `target_iphone` 박스를 그립니다.
- 목표 기종이 아닌 휴대폰은 외곽 전체에 `other_phone` 박스를 그립니다.
- 깨진 제품은 휴대폰 전체 박스와 함께 깨진 영역에 `crack` 박스를 추가합니다.
- 물체가 없는 컨베이어 사진은 박스를 그리지 않고 **라벨 저장**을 눌러 빈 라벨 파일을 만듭니다.
- 같은 제품이라도 위치, 회전, 밝기, 배경을 바꾼 사진을 포함합니다.
- 학습용과 검증용 사진이 거의 동일한 연속 프레임이 되지 않도록 촬영 묶음을 나누는 것이 좋습니다.

## 구성

- 사용자 화면과 라벨 저장: C# WinForms
- YOLO 학습: Python Ultralytics
- 결과 배포: ONNX

Ultralytics의 Python 학습 API는 `model.train(data=..., epochs=..., imgsz=...)` 형식을 사용하고, 학습된 모델은 `format="onnx"`로 변환합니다.
