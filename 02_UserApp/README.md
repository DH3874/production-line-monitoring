# 사용자 C# WinForms

현재 흐름: **카메라·벨트 연결 → 검사 시작 → 벨트 구동 → 이동 중 인식 → 결과·사진 저장 → 계속 이동**.

- 휴대폰 검출 시 정지 체크박스, 벨트 정지 버튼, 정지 대기·재검사·완료 해제·자동 재구동 기능을 제거했습니다.
- 검사는 목표 100ms 간격으로 계속합니다. 실시간 영상은 계속 갱신하고 마지막 인식 결과·사진은 새 제품이 인식될 때만 바뀝니다.
- 검사 중지는 영상 분석·기록만 중지합니다. 벨트 연결 관리와 통신 중단 처리는 유지합니다.
- 같은 휴대폰은 한 번 기록하고, 마지막 검출 후 250ms 이상 지난 빈 화면을 확인하면 다음 제품을 기록합니다. 제품 간 빈 구간이 필요합니다.
- **검사 개수 · 지난 기록**에서 행을 선택하면 오른쪽에 해당 기록의 인식 제품 사진이 표시됩니다. 사진이 없는 이전 기록·시뮬레이션은 사진 없음으로 표시합니다.
- 사진은 인식한 프레임의 박스가 포함된 JPEG로 서버에 검사 ID와 함께 저장합니다. 긴 변은 최대 1280px입니다. 다른 PC·재실행 후에도 권한에 따라 조회할 수 있습니다.
- 사진 저장 기능 적용에는 **서버와 사용자 앱 모두 재실행**이 필요합니다. 기존 서버는 새 사진을 저장할 수 없습니다.

기본 6클래스 ONNX 모델과 모델 선택·학습 도구, 문제·조치, AI 상담·관리자 문의는 유지합니다. 현재 검증되지 않은 정상/불량은 판정 불가로 기록하고 실제 신뢰도를 저장합니다.

검증: Verification 프로젝트에 `--moving-inspection "아이폰 샘플.jpg"`를 전달합니다. 실제 ONNX와 모의 장치·서버를 사용하며 물리 모터는 구동하지 않습니다. 서버·저장·조회 권한·재시작 및 기록 선택 검증은 `tools/IntegrationVerification`에 있습니다.
