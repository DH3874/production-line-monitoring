# 관리자·AI 상담 통합 실행 안내

`01_AdminApp.zip`과 `05_AiAssistant.zip`의 소스를 기존 `ProductionLineSystem.sln`에 통합했습니다. 별도 압축파일의 솔루션을 열 필요는 없습니다.

## 실행

1. 실행 중인 관리자·사용자·서버 프로그램을 종료합니다.
2. 프로젝트 루트의 `ProductionLineSystem.sln`을 열고 솔루션을 빌드합니다.
3. `ProductionLine.Server`를 먼저 실행합니다.
4. `ProductionLine.AdminApp`, `ProductionLine.UserApp`을 각각 실행합니다.
5. 초기 관리자 계정은 `admin / admin123!`, 사용자 계정은 `worker1 / worker123!`입니다. 이미 변경한 비밀번호가 있으면 변경한 값을 사용합니다.

## 관리자 확인

- 로그인하면 실제 서버의 전체 라인 현황이 표시되며 5초마다 갱신됩니다.
- 대표 라인을 더블클릭하면 라인 상세가 열립니다. 가상 라인은 현황만 표시합니다.
- 사용자 관리에서 계정 추가·수정·비밀번호 변경·허용 라인 변경·비활성화를 처리합니다. 기존 로그인 세션은 계정 수정 시 만료되므로 사용자 앱에서 다시 로그인합니다.
- 사용자의 `발생 → 확인 → 조치 중 → 완료 요청` 이후 관리자가 완료 요청 확인에서 종결 또는 반려합니다. 반려하면 사용자가 다시 조치하고 완료 요청할 수 있습니다.
- 검사 이력/통계는 서버에서 받은 최근 검사 기록(라인별 최대 100건)에 대한 통계입니다.

## AI 상담 확인

1. 사용자 앱의 문제·조치 탭에서 라인 문제를 등록합니다.
2. AI 상담 탭에서 그 문제를 선택하고 `카메라 영상이 안 나와요` 또는 `습도가 높아요`처럼 질문합니다.
3. `80%`, `있어요` 같은 후속 답변을 입력하면 사용자·라인·문제별 문맥을 이어갑니다. `새 상담`으로 문맥을 초기화합니다.
4. 답변의 매뉴얼 근거와 관리자 확인 필요 표시를 확인합니다. 관리자 확인 표시는 자동 전송이 아니며, 관리자 상담 탭에서 문의를 보내야 합니다. 문의는 관리자 문제 조회에서 확인합니다.

API 키가 없으면 `[AI 연결이 설정되지 않아 기본 매뉴얼 안내를 제공합니다]`로 시작하는 답변이 나옵니다. 서버 연동 오류가 아니라 기본 매뉴얼 모드라는 의미입니다. 생성형 상담 설정은 [GEMINI_SETUP.md](GEMINI_SETUP.md)를 참고하세요.

## 보존과 제한

- 기존 사용자·검사·문제 저장소와 YOLO 모델/0.1초 연속 검사 코드를 유지합니다.
- 통합 전 소스는 `output/backups/before-admin-ai-integration-*.zip`에 있습니다.
- AI 문맥은 서버 메모리에 보관되므로 서버를 재시작하면 초기화됩니다. 사용자 화면 표시 이력은 이 PC의 사용자별 로컬 파일에 남습니다.
- 실제 생성형 API 사용에는 서버 API 키와 선택한 모델의 사용 권한이 필요합니다. 이번 통합 검증은 외부 유료 호출 없이 수행합니다.
