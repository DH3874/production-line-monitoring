# 역할 분담과 병합 규칙

## 브랜치

- `feature/admin-*`: 1번
- `feature/user-*`: 2번
- `feature/server-*`: 3번
- `feature/vision-*`: 4번
- `feature/ai-*`: 5번

## 병합 순서

1. 각자 `main` 최신 내용을 자기 브랜치에 반영합니다.
2. 자기 프로젝트를 포함해 솔루션 전체를 빌드합니다.
3. 담당 기능의 로그인부터 저장까지 직접 확인합니다.
4. 3번 통합 담당자가 공용 DTO와 API 호환성을 확인합니다.
5. 매일 작은 단위로 `main`에 병합합니다.

`00_Shared`와 솔루션 파일은 충돌이 가장 많이 생기는 영역이므로 3번 담당자가 최종 반영합니다.
