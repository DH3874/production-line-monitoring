# 공개 범위 및 민감정보 점검

점검일: 2026-10-27. 저장소 준비를 위한 정적 검색과 설정·인증·저장 로직 확인 결과이며 완전한 보안 감사를 뜻하지 않는다. 발견 후보의 실제 값이나 기존 사용자 DB 내용은 이 문서에 복사하지 않았다.

## 확인 결과

| 항목 | 결과 및 처리 |
|---|---|
| Gemini/OpenAI/GitHub 토큰·개인 키 | 검색한 소스·설정·문서·스크립트에서 실제 키 형태 미발견 |
| AI 테스트의 키 값 | 가짜 HTTP 응답 검사용 테스트 문자열·문서의 입력 자리표시자 확인 |
| DB 접속 설정 | 외부 DB 계정·비밀번호 사용 없음. 서버 ContentRoot의 로컬 SQLite 파일 사용 |
| 기본 계정 | 코드와 문서에 시연용 초기 ID·비밀번호 존재. 실제 외부 서비스 자격증명으로 분류하지 않았고 기능 보존을 위해 유지 |
| 비밀번호 저장 | SQLite에는 PBKDF2-SHA256 해시 저장. 생성·로그인 흐름 확인 |
| 인증 토큰 | 로그인 성공 후 임의 32바이트 토큰 생성, 서버 메모리 8시간 세션. 저장소에 실행 토큰 포함하지 않음 |
| 저장된 Gemini 키 | `%LOCALAPPDATA%/ProductionLine/gemini-key.dpapi`를 읽는 코드 확인. 프로젝트 밖의 키 파일을 읽거나 복호화·복사하지 않음 |
| 실행 DB·단체 채팅·로그 | 준비본에서 제외. 기존 실제 파일은 원본 위치에 유지 |
| 사설 IP·개인 PC 경로 | 접속 예시와 과거 문서/학습 보조 스크립트에 존재. 현재 README에는 서버 IP 자리표시자 사용. 과거 파일은 원본대로 보존 |
| Git 이력 | 전달된 프로젝트 루트에 `.git` 없음. 별도 준비본에서 새 로컬 저장소를 구성하며 과거 데이터 이력을 가져오지 않음 |

## 업로드 제외 대상

- `bin/`, `obj/`, `.vs/`, `.dotnet-home/`, 사용자별 IDE 설정
- 서버 `App_Data/` 전체: SQLite·WAL·SHM·통신 기록 백업
- 서버 `data/` 전체: 채팅·검사 사진·AI 진단·마이그레이션 전 저장 데이터
- `.env` 실제 설정, 암호화 키·개인 키·인증서·로컬 비밀 설정
- 로그·임시 파일·Python 캐시·새 학습 출력·새 패키징 출력

`.gitignore`는 이미 커밋한 파일을 과거 이력에서 제거하는 도구가 아니다. 이 준비본은 기존 실행 기록을 복사하지 않은 상태에서 Git을 초기화한다. 원본의 파일을 삭제하거나 기존 저장소 이력을 다시 쓰지 않았다.

## 유지한 필수 자료

- `04_Vision/models/`의 ONNX·메타데이터·배경 기준 이미지
- 실행/검증에 참조하는 샘플 이미지와 라벨
- `tools/arduino-cli/arduino-cli.exe`와 출처·라이선스
- Mega 펌웨어와 포함 라이브러리·고지 파일
- 시연용 기본 계정과 테스트 계정 코드

## 승인 없이 변경하지 않은 부분

시연 계정의 초기 비밀번호나 계정 생성 정책은 기능에 영향을 주므로 변경하지 않았다. 개인 경로 제거, 문서 이동, 보조 스크립트 정리, 자체 코드의 공개 라이선스 부여도 별도 검토 대상으로 남겼다. 공개 준비와 실제 업로드는 분리했으며, 점검 이후 사용자 승인을 받아 GitHub 저장소를 공개하고 준비본을 업로드했다.
