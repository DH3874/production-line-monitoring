# 담당 역할과 기술적 성과

## 팀 전체 기능과 본인 담당 구분

5명 공동 프로젝트로 관리자 앱, 작업자 앱, 서버·저장소·통신, 영상처리·학습, 상담 AI를 나누어 구현했다. 이 저장소의 포트폴리오 설명은 사용자와의 작업 이력을 바탕으로 **상담 AI·매뉴얼과 채팅 기능**에 초점을 맞췄다. 서버·DB 전체나 최종 통합 YOLO 모델의 학습을 개인 단독 성과로 주장하지 않는다. 팀 저장소를 공개하기 전 최종 역할 표기는 팀원과 확인할 수 있다.

## AI 상담

- 16개 공정 매뉴얼을 JSON으로 정리하고 질문 키워드·이전 상담 주제로 관련 자료를 선택한다.
- 기본 매뉴얼 상담을 유지하면서 외부 Gemini/OpenAI 호출을 연결한다.
- 사용자/라인/상담 ID별 최근 대화를 관리하고, 동일 세션 동시 요청을 직렬화한다.
- 제공된 매뉴얼 ID만 답변 근거로 사용할 수 있게 응답 스키마와 파서를 검증한다.
- 근거 부족, 호출 제한, 네트워크 실패, 시간 초과를 구분해 안내한다.
- 서버 설정 준비, 실제 AI 응답 결과, 응답 시간을 화면에서 구분한다.
- 센서·장비 보고는 수신 시각과 확인 범위를 함께 전달하며, AI가 장비 명령을 수행하지 않도록 구분한다.

## 단체 채팅

- 관리자·작업자 앱에서 공통 UI 소스를 재사용한다.
- 2초 폴링과 마지막 수신 ID 기반 증분 조회를 구현한다.
- 서버 수신 순서 ID, 클라이언트 전송 ID를 나누어 표시 순서와 재시도 중복을 처리한다.
- 파일 저장 성공 후 메모리에 반영하고, 실패하면 작성 중 내용을 유지한다.
- 읽지 않은 메시지 수, 전송 상태, 자동 스크롤을 표시한다.

## 관리자 상담 연동

- 기존 문제 상태 흐름과 서버 API를 이용해 문제별 메시지를 연결한다.
- 작업자는 조치 중일 때 전송하고 완료 요청 후에는 읽기 전용으로 확인한다.
- 문제 전환이나 자동 새로고침 중에도 작성 중인 초안을 보존한다.
- 관리자 완료 요청 검토 화면과 같은 문제의 대화를 공유한다.

## 설명할 수 있는 기술적 선택

| 문제 | 선택한 방식 | 확인 가능한 근거 |
|---|---|---|
| 관련 없는 매뉴얼로 모든 질문에 같은 답변 | 현재 질문의 자료 선택과 짧은 후속 답변 문맥을 구분 | ManualAssistant.Scope.cs, AiReferences.cs |
| 외부 AI 장애로 상담 중단 | 기본 매뉴얼 대체와 원인별 상태 코드 | AiConsultationService.cs |
| AI가 출처를 만들어 냄 | 자료 ID enum과 서버 측 검증 | AiResponseProtocol.cs |
| 설정된 키가 있다는 이유로 연결 성공 표시 | 설정 준비와 실제 생성 성공 별도 표시 | AiChatStatusPanel.cs, AiReplyStatus.cs |
| 응답 유실 후 채팅 재전송 중복 | ClientMessageId로 기존 메시지 반환 | GroupChatStore.cs |
| 화면 새로고침 때문에 작성 내용 사라짐 | 전송 실패·문제 전환 시 초안 유지 | GroupChatPanel.cs, IssueChat.cs |

## 수치의 범위

현재 준비본 검증에서는 AI 관련 기존 검사 196개, 모의 원격·프로토콜·타이밍 검사 66개, 격리 HTTP API 검사 25개가 통과했다. 이 수치는 2026-10-27 코드 준비 과정에서 실행한 검증 결과이며, 개인 개발 당시의 성능 지표나 실제 설비의 신뢰성 인증 수치가 아니다. 모델 mAP·실제 분류 정확도·생산성 개선율은 근거 자료가 없어 기재하지 않았다.
