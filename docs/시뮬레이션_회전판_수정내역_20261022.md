# 회전 분류판 시뮬레이션 수정 — 2026-10-22

## 적용 내용

- 대표 실제 라인과 가상 라인 2·3·4, 대표 라인 상세 화면에 회전판 그림을 적용했습니다.
- 컨베이어, 인식부, 상단 불량 분류함, 하단 모터 축과 회전 분류판을 첨부 GIF와 같은 구성으로 표시합니다.
- 가상 LINE 2는 정상 전용입니다. 정상 제품만 반복 투입하며 판을 수평으로 고정한 채 직진 통과합니다.
- 가상 LINE 3은 불량 전용입니다. 불량 제품만 반복 투입하며 판을 55° 회전시켜 분류함으로 보내고 수평으로 복귀합니다.
- 가상 LINE 4는 정상·불량 혼합입니다. 정상 통과와 불량 분류를 번갈아 반복합니다.
- 세 가상 라인의 시작 위치·시점을 다르게 설정했습니다. 자동 새로고침으로 시연이 초기화되거나 서로 같은 시점으로 맞춰지지 않습니다.
- 각 가상 카드의 정상/불량 수량은 초기 시연 수량에 해당 라인이 실제로 시연 완료한 결과를 더해 표시합니다. 정상 전용 라인의 불량 수량과 불량 전용 라인의 정상 수량은 0입니다.
- 작은 대시보드 카드에서도 컨베이어가 가로 폭에 맞게 표시됩니다. 기존 네 라인 2×2 배치는 유지합니다.
- 가상 카드의 긴급 정지 버튼은 움직임을 멈추며, 자동 새로고침으로 해제되지 않습니다. 버튼으로 해제하면 이어서 재생합니다.
- 관리자 메인의 `문의 / 답변` 메뉴와 전용 `IssueMessagesForm.cs`를 삭제했습니다.
- 완료 요청 확인 화면에서 사용하는 문제별 대화와 단체 채팅은 별도 기능으로 유지했습니다.

## 실제 장비 연동

- 대표 라인의 벨트 움직임은 연결된 장비의 구동·정지·긴급 정지·가속 상태를 따릅니다.
- 대표 라인의 분류판 각도는 서버에서 받은 `SorterAngle`을 표시합니다.
- 연결 상태가 오래되거나 실제 벨트가 정지하면 대표 라인의 이동 애니메이션도 멈춥니다.
- 제품 위치 그림은 시각적인 이동 예시이며 실제 제품 위치 측정값이 아닙니다. 실제 생산 수량을 시뮬레이션이 변경하지 않습니다.
- 기존 전체 정지 명령과 응답 확인 절차는 유지했습니다.
- 서버 API, 공용 Contracts, SQLite 데이터, 작업자 프로그램 및 하드웨어 펌웨어는 변경하지 않았습니다.
