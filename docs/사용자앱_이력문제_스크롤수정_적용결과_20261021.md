# 사용자 앱 이력·문제 스크롤 수정 적용 결과

2026-10-21, 전달 문서 `GPT_전달용_사용자앱_스크롤수정_v5_2026-10-21.md`의 기능 설명을 현재 소스에 적용했다. 수정 소스가 별도로 전달된 것이 아니므로 기존 파일을 덮어쓰지 않고 해당 함수와 이벤트를 수정했다.

- 검사 이력: 동일 값/순서이면 DataSource 유지. 변경 시 선택 검사 ID·열 이름·첫 표시 검사 ID·가로 위치 복원.
- 문제 목록: 동일 데이터 재바인딩 생략. 변경 시 문제 ID 기준 선택/보기 위치 복원. CurrentCellChanged에서 문제 선택 처리.
- 문제 상세: 같은 문자열 재대입 생략. 같은 문제의 상태·메모 변경 시 글자 선택과 첫 표시 줄 유지.
- 조치 입력: 기존 문제별 초안 보관을 유지하며 자동 갱신 때 입력 내용을 덮어쓰지 않는다. 상태 변경에 따른 읽기 전용/버튼 권한은 갱신한다.

변경: `InspectionHistory.cs`, `UserMainForm.cs`. 추가: `GridViewportState.cs`, `IssueListBinding.cs`, `tools/ScrollVerification`.
